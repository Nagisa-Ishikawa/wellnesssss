# 健康管理アプリ 技術仕様書

## 概要
Google Pixel8向けのAndroid健康管理アプリの技術仕様

## 技術選定

### フレームワーク
- **Flutter** 
  - Androidネイティブ対応
  - 高いパフォーマンス
  - 豊富なUIコンポーネント
  - カレンダーやグラフ表示に適したライブラリが充実

### データベース
- **SQLite** - 構造化された健康データの管理
- **Hive** - 設定やキャッシュデータの高速アクセス

### 主要ライブラリ
- `table_calendar` - カレンダー表示
- `fl_chart` - グラフ表示  
- `sqflite` - SQLiteデータベース
- `hive` - NoSQLデータベース
- `provider` - 状態管理

### 開発環境
- Flutter SDK 3.x
- Dart 3.x
- Android SDK
- VS Code / Android Studio

## アーキテクチャ
- MVVM (Model-View-ViewModel) パターン
- Provider による状態管理
- Repository パターンによるデータアクセス層の抽象化

## ターゲット
- Android 8.0 (API level 26) 以上
- Google Pixel8 での動作保証
