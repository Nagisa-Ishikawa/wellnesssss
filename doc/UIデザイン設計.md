## UI/UXガイドライン

### カラーパレット
```dart
// Primary Colors
Color primary = Color(0xFF6B73FF);
Color primaryVariant = Color(0xFF3F51B5);
Color secondary = Color(0xFFFF6B9D);

// Health Status Colors
Color moodExcellent = Color(0xFF4CAF50);
Color moodGood = Color(0xFF8BC34A);
Color moodNormal = Color(0xFFFFEB3B);
Color moodPoor = Color(0xFFFF9800);
Color moodBad = Color(0xFFF44336);

// Background Colors
Color background = Color(0xFFF5F5F5);
Color surface = Color(0xFFFFFFFF);
```

### タイポグラフィ
- **見出し**: Roboto Bold 18-24sp
- **本文**: Roboto Regular 14-16sp
- **キャプション**: Roboto Light 12sp

### インタラクション設計

#### カレンダー
- タップ: 該当日の記録画面へ遷移
- 長押し: 日付の記録概要をポップアップ表示
- スワイプ: 月移動

#### 記録項目
- フォーカス時に項目をハイライト
- 入力完了時にチェックマーク表示
- エラー時に赤枠とメッセージ表示

#### グラフ
- タップ: データポイントの詳細表示
- ピンチ: ズーム機能
- スワイプ: 期間変更

### アクセシビリティ
- 十分なコントラスト比（4.5:1以上）
- タップターゲット最小44dp
- スクリーンリーダー対応
- フォントサイズ調整対応
