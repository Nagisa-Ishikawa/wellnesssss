# データベース設計

## データベース構成

### SQLite（構造化データ）
健康記録の主要データを管理

### Hive（設定・キャッシュ）
アプリ設定とキャッシュデータを管理

## SQLite テーブル設計

### 1. health_records テーブル
日次の健康記録メインテーブル

```sql
CREATE TABLE health_records (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    date TEXT NOT NULL UNIQUE,           -- YYYY-MM-DD形式
    mood_level INTEGER,                  -- 1-5 (悪い〜良い)
    diary_text TEXT,                     -- 日記テキスト
    body_temperature REAL,               -- 体温
    weight REAL,                         -- 体重
    blood_pressure_systolic INTEGER,     -- 収縮期血圧
    blood_pressure_diastolic INTEGER,    -- 拡張期血圧
    heart_rate INTEGER,                  -- 心拍数
    created_at TEXT NOT NULL,            -- 作成日時
    updated_at TEXT NOT NULL             -- 更新日時
);
```

### 2. symptoms テーブル
不調症状の記録

```sql
CREATE TABLE symptoms (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    health_record_id INTEGER NOT NULL,
    symptom_type TEXT NOT NULL,          -- 頭痛、腹痛、吐き気等
    notes TEXT,                          -- 備考
    FOREIGN KEY (health_record_id) REFERENCES health_records(id)
);
```

### 3. menstrual_records テーブル
月経記録

```sql
CREATE TABLE menstrual_records (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    health_record_id INTEGER NOT NULL,
    flow_level INTEGER,                  -- 経血量レベル 1-5
    pain_level INTEGER,                  -- 生理痛レベル 0-5 (0=なし)
    pms_irritability BOOLEAN DEFAULT FALSE,
    pms_headache BOOLEAN DEFAULT FALSE,
    pms_abdominal_pain BOOLEAN DEFAULT FALSE,
    pms_breast_tenderness BOOLEAN DEFAULT FALSE,
    pms_swelling BOOLEAN DEFAULT FALSE,
    pms_other TEXT,                      -- その他PMS症状
    FOREIGN KEY (health_record_id) REFERENCES health_records(id)
);
```

### 4. symptom_types テーブル（マスターデータ）
設定可能な症状タイプ

```sql
CREATE TABLE symptom_types (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    name TEXT NOT NULL UNIQUE,           -- 症状名
    display_order INTEGER NOT NULL,     -- 表示順序
    is_active BOOLEAN DEFAULT TRUE       -- 使用可否
);
```

## Hive データ構造

### 1. AppSettings
アプリケーション設定

```dart
@HiveType(typeId: 0)
class AppSettings extends HiveObject {
  @HiveField(0)
  List<String> visibleHealthFields;    // 表示する健康記録項目
  
  @HiveField(1)
  List<String> healthFieldOrder;       // 健康記録項目の表示順序
  
  @HiveField(2)
  List<String> visibleSummaryCharts;   // サマリーに表示するグラフ
  
  @HiveField(3)
  List<String> summaryChartOrder;      // サマリーグラフの表示順序
  
  @HiveField(4)
  bool mondayStart;                    // カレンダー月曜始まり
}
```

### 2. CustomSymptomTypes
カスタム症状タイプ

```dart
@HiveType(typeId: 1)
class CustomSymptomTypes extends HiveObject {
  @HiveField(0)
  List<String> symptomTypes;           // カスタム症状リスト
}
```

## インデックス設計

```sql
-- 日付での高速検索
CREATE INDEX idx_health_records_date ON health_records(date);

-- 月次・年次でのデータ取得最適化
CREATE INDEX idx_health_records_date_range ON health_records(date, created_at);

-- 症状検索最適化
CREATE INDEX idx_symptoms_record_type ON symptoms(health_record_id, symptom_type);
```

## データ制約・バリデーション

### 必須フィールド
- date: 日付（YYYY-MM-DD）
- created_at, updated_at: タイムスタンプ

### データ範囲
- mood_level: 1-5
- body_temperature: 30.0-45.0
- weight: 20.0-300.0  
- blood_pressure: 50-300
- heart_rate: 30-200

### 論理制約
- 同一日付の重複記録不可
- 未来日付の記録不可
