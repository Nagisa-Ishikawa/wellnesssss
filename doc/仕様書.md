# 健康管理アプリ 仕様書

## アプリ概要
Electron製の健康管理デスクトップアプリケーション。

## 技術スタック
- Electron
- React
- TypeScript
- Chart.js (グラフ表示)
- LocalStorage (データ永続化)

## 画面構成

### 1. ホーム画面
- **ヘッダー**
  - 画面右上に歯車アイコン（設定画面への遷移）
- **カレンダー表示**
  - 月曜始まりの週表示
  - 体調記録がある日は色付き表示（良い: 緑、普通: 黄、悪い: 赤）
  - 日付クリックで記録画面へ遷移
- **サマリー表示**
  - 体調記録のグラフ（週/月単位）
  - 項目と表示順は設定で変更可能

### 2. 体調記録画面
- **ヘッダー**
  - 画面右上に歯車アイコン（設定画面への遷移）
- **気分記録**
  - 5段階選択（良い、やや良い、普通、やや悪い、悪い）
  - 日記入力（テキスト）
- **体調記録**
  - 体温（数値入力）
  - 体重（数値入力）
  - 血圧（数値入力・上/下）
  - 心拍数（数値入力）
  - 不調（複数選択、備考欄付き）
- **月経記録**
  - 経血量（3段階）
  - 生理痛有無（チェックボックス）
  - PMS症状（複数選択、その他入力欄）

### 3. 設定画面
- 記録項目の表示/非表示
- 項目表示順の変更
- 不調項目の編集
- サマリー表示項目の設定
